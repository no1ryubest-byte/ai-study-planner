# プレゼン資料

プチプロコンの発表で使うスライド（.pptx）を置くフォルダです。

| 場所 | 中身 |
|---|---|
| `プチプロコンプレゼン_マナビクス.pptx` | 発表用のスライド（4:3・全15枚）。各スライドの発表者ノートに、話す内容と時間の目安を書いています |
| `logo/` | マナビクスのロゴ（背景を消したもの）。`_w` が付いたものは、青い背景用に文字を白くした版 |
| `patterns/` | 表紙と上の帯の模様（PNG と、元の SVG） |
| `icons/` | アプリのアイコン案（SVG）と、一覧の画像 `sheet.png` |

## 発表のときのメモ

- 発表者ツール（スライドショー → 発表者ツールを使用する）を使うと、プロジェクターにはスライドだけ、手元の画面には発表者ノートが表示されます。
- デモ（P09）は PC のブラウザで行います。`node build.js` で `dist/preview.html` を作って開きます。この開き方では AI 機能は動きません。
